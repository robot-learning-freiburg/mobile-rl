# Running MoMa-CoDesign Optimization with devcontainer
1. On your host/local machine run `xhost +local:docker`
2. replace all values named "todo" in devcontainer.json
3. build devcontainer
4. Source workspace for robot, activate environment and disable sigint handler (else trainer crashes)
```
source /root/catkin_ws_fmm/devel/setup.bash
conda activate base
export TUNE_DISABLE_SIGINT_HANDLER=1
```

5. Note, c++ code is copied into robot workspaces atm. Changes to it will only take effect after rebuilding the container

6. show fmm robot:
```
roslaunch modulation_rl fmm_robot.launch
```
7. Run the design optimization process. Note this may take a long time (up to a week) to fully run. 
```
nohup python3 scripts/optimize_design.py &
```

8. Evaluate a robot design on specific tasks for `--nr_evaluations` iterations on the tasks defined in `evaluation_design.py` : first update the run_names in `evaluation_logging_paths.py` to match the correct runs generated by step 7. Then set the `names` of which of these configurations to evaluate in `evaluation_design.py` and run the following :
```
python3 scripts/evaluation_design.py --vis_env yes --debug true --env fmm --load_best_default --use_map_obs yes --ray_verbosity 0 --training_intensity 0 --num_workers 0 --model_file checkpoint-1000 --evaluation_only True --nr_evaluations 10 --seed 42
```


### Use UR5 arm
- Change Dockerfile and checkout the ur5_arm branches of these two repos:
```
RUN git clone https://github.com/robot-learning-freiburg/fmm_moveit_config.git src/fmm_moveit_config \
    && cd src/fmm_moveit_config   \
    && git checkout UR5-arm 


RUN git clone https://github.com/robot-learning-freiburg/fmm_description.git src/fmm_description \
    && cd src/fmm_description \
    && git checkout UR5-arm 
```
- change arm_selection to 'ur5_arm' in run_config.yaml
